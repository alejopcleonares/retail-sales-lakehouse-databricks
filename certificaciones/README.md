# Certificaciones y validaciones del proyecto

Esta carpeta documenta las validaciones técnicas utilizadas como evidencia de cumplimiento del proyecto.

## Validaciones realizadas

- Validación de conectividad con Azure Data Lake Storage Gen2.
- Acceso a Raw mediante Managed Identity.
- Validación de cinco datasets de origen.
- Reconciliación Bronze, Silver y Quarantine.
- Validación de tablas analíticas Gold.
- Auditoría de calidad mediante `data_quality_summary`.
- Validación de permisos mediante Unity Catalog.
- Ejecución satisfactoria del Workflow productivo de Databricks.
- Validación CI mediante GitHub Actions.
- Despliegue y ejecución CD desde GitHub Actions hacia Azure Databricks.
